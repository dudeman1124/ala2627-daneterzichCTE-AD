# Vector Run

An original browser racing game inspired by the broad ideas of looping tracks, time trials, and lightweight driving physics. It does not use Polytrack code or assets.

## Run it

From the workspace root:

```bash
python3 -m http.server 8000 --directory Polytrack-Inspiration
```

Then open `http://localhost:8000/`.

Controls: `WASD` to drive, `Space` to brake, `Escape` to pause, and `R` to reset.
