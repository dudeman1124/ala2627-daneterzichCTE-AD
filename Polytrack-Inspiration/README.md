# Vector Run

An original third-person 3D browser racing game inspired by the broad ideas of looping tracks, time trials, and lightweight driving physics. It does not use Polytrack code or assets.

## Run it

From the workspace root:

```bash
python3 -m http.server 8000 --directory Polytrack-Inspiration
```

Then open `http://localhost:8000/`.

Controls: `W` accelerates, `S` drives backward, `A/D` steer, `Space` brakes, `Escape` pauses, and `R` resets. The game uses Three.js from jsDelivr, so the browser needs internet access when it loads.
