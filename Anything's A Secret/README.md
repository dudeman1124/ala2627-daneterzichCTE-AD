# Anything's A Secret

A browser-based, first-person puzzle world. Open this folder's `index.html` through the repository's web server
(for example, `python -m http.server 8000` from the repository root), then visit `/Anything's%20A%20Secret/`.

Click **Step Into the World** to begin. Use **WASD** to move, **Space** to jump, and **;** to toggle mouse capture.
Enter a discovered phrase in the secret box and press Enter to unlock it.

The map is 2,000 feet square. One Three.js world unit represents one foot; the player is 6 feet tall, with an eye
height of 5.5 feet and a 2-foot jump. Three.js is loaded from jsDelivr.
